Phase 1 Mask Usage Analysis

Date: 2026-05-21
Branch: feat/masking-loss-reevaluation
Scope: Training-path mask behavior mapping while A2 ablation remains active.

Executive Summary

Masking currently affects optimization directly, not only reporting. Mask generation and union happen in the dataloader, semantic inversion occurs at the training loss boundary, and custom losses primarily use full-shape valid_mask inputs. A fallback path still exists for criteria without valid_mask support.

A. Mask Usage Overall

  1. Mask creation starts in src/synthoseis_pre_train/masking.py via create_mask_3d.
  2. Source semantics are explicit: True preserve, False masked in apply_mask_to_seismic.
  3. Dataloader applies masking to input only and keeps target unmasked.
  4. Optional cluster expansion dilates blank-trace adjacency and reapplies masking.
  5. Final mask is trace_mask & geom_mask.
  6. Training consumes mask via _compute_masked_loss.
Risk: dataloader comments and train-time inversion semantics need a single explicit contract to avoid drift.

B. Mask Usage In Loss Computation

  • train.py::_compute_masked_loss computes valid_mask = ~mask.
  • If criterion supports valid_mask, full-shape tensors are passed.
  • Fallback path is restricted to pointwise criteria or explicit opt-in via allow_mask_indexing=True.
  • Unsupported criteria now fail fast with a clear error instead of silent flattening.

Mask-aware losses confirmed: SSIMMSELoss3D, MONAIStyleSSIMMSELoss3D, SlidingWindowStatsLoss3D, CompositeClusterAwareLoss.

C. Mask Usage In Gradient Backpropagation

  1. Train loop computes masked loss.
  2. Backward is executed on scaled masked loss.
  3. Gradients are clipped and optimizer steps on accumulation boundaries.

Masked regions are excluded where valid-mask weighting is zero. Composite cluster-aware loss shifts gradient emphasis by region.

D. Mask Usage Restricted To Diagnostics And QC

  1. QC block is now opt-in and recomputes additional masked losses only when explicitly enabled.
  2. Per-batch stats and figures are emitted for diagnostics.
  3. plotting.py consumes volumes and does not directly consume mask tensors.
Boundary update: default training path is no longer coupled to per-batch QC recomputation unless --enable_batch_qc_metrics is set.

E. MONAI 1.0.0 Pattern Comparison

Alignment:

  • Loss modules generally support explicit mask-aware full-shape contracts.
  • Masking and reduction are handled inside loss modules.

Divergence:

  • Runtime signature inspection remains, but unsupported routing is now fail-fast.
  • QC recomputation is now opt-in and interval-gated, reducing hot-path coupling.
  • Mask inversion at train boundary should be formalized in one contract.
