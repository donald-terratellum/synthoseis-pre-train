  • Implemented hybrid objective: w1 * (1 - SSIM) + w2 * MSE + w3 * L1.
  • Normalized seismic amplitudes for SSIM using x01 = clamp(x / 20 + 0.5, 0, 1) to map approx [-10, 10] to [0, 1].
  • Used standard SSIM constants consistent with common implementations/literature: K1=0.01, K2=0.03, L=1.
  • Added train CLI args: --loss ssim, --ssim_window_size, --ssim_w1, --ssim_w2, --ssim_w3.
  • Added runtime guards for valid SSIM window and weights.
  • Updated stdout summary to use named terms: ssim_term, mse_term, mae_term.
